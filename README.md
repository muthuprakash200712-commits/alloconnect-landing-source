# AlloKonnect Landing Page Concept

A premium, responsive landing page concept built with React, TypeScript, Vite, and Tailwind CSS v4. It uses a custom CSS product mockup, Lucide icons, responsive navigation, feature cards, FAQ accordion, official store links, and a demo email form.

## Requirements
- Node.js 20.19+ or 22.12+
- npm

## Run locally

```bash
cd "C:\Users\rajes\Downloads\alloconnect-landing-source\alloconnect-landing"
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

The production site is generated in `dist/`.

## Customize before submitting
- Confirm approved brand colors, logo assets, product screenshots, copy, and CTA destinations with the internship supervisor.
- Replace the CSS-created mock app UI with official screenshots if permitted.
- The email form is frontend-only and does not send or store email addresses. Connect it to an approved backend/service before production.
- This is an independent internship redesign concept, not an official AlloKonnect website. Do not imply the landing page is operated by the company without approval.
